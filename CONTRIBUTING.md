# Contributing to Pupil

Thanks for taking the time to look at Pupil. This document covers how to get the project running, what the review bar is, and the conventions that will save you a round trip.

## Getting set up

Pupil is a Bun workspace containing the desktop app (`apps/app`) and the marketing site (`apps/site`).

```bash
bun install
```

`bun install` runs the repo `prepare` script, which installs [Lefthook](https://github.com/evilmartians/lefthook) as a `pre-commit` hook.

Building the desktop app also needs a Rust toolchain and, on Linux, a handful of system libraries. Those prerequisites are listed in [`BUILDING.md`](./BUILDING.md).

The `pre-commit` hook runs `cargo fmt` and `cargo clippy`, so make sure the pinned toolchain has both components installed:

```bash
rustup component add --toolchain "$(cat rust-toolchain.toml | grep channel | cut -d'"' -f2)" rustfmt clippy
```

Without them the hook fails on a fresh clone even though nothing is wrong with your changes.

## Running things

```bash
bun run --cwd apps/app dev    # desktop app (Tauri shell + Vite)
bun run --cwd apps/site dev   # marketing site
bun dev                       # both
```

The desktop `dev` script enables the `mcp-bridge` cargo feature. That plugin exposes arbitrary JS and shell command execution over a local socket to make the app drivable in development. It is a development aid only, it is compiled out of any build that does not explicitly opt in, and its capability grant is registered at runtime rather than from `capabilities/`. **Do not add `mcp-bridge` to a release build or move its permission into `capabilities/default.json`.**

## Before you open a pull request

Run the full check matrix. CI runs exactly these, so a green local run means a green CI run:

```bash
bun run lint
bun run typecheck
bun run test
bun run lint:rust
bun run format:check
```

Coverage, when you want it:

```bash
bun run test:coverage
```

## Conventions

Repo-wide architecture, module boundaries, and testing conventions live in [`AGENTS.md`](./AGENTS.md), with app-specific detail in [`apps/app/AGENTS.md`](./apps/app/AGENTS.md) and visual language in [`apps/app/DESIGN.md`](./apps/app/DESIGN.md). Those files are the source of truth; the highlights:

- **SQLite is the canonical persisted state** for the desktop app.
- **AI secrets never touch SQLite.** They live in the OS keychain (macOS) or a Stronghold vault keyed from the OS secure store (elsewhere).
- **FSRS scheduling stays in TypeScript.** Rust persists validated results rather than recomputing schedules.
- **Migrations are append-only** and registered through the typed `MIGRATIONS` registry.
- **CSS is fully modular.** Component styles live in collocated `*.module.css` files; do not add component rules to `src/styles/shared.css`.
- **Card text is escaped before rendering.** Anything rendered through `dangerouslySetInnerHTML` must go through `src/lib/card-markup.ts`. Do not write a second escaping routine.

### Generated files

`apps/app/src-tauri/gen/schemas/` is regenerated by `tauri-build` on every build and is not tracked in git — its contents vary by platform and by enabled cargo features. The `$schema` reference in `capabilities/default.json` resolves after your first build.

## Commits and pull requests

- Keep the working tree passing before you commit; the hook is a safety net, not a formatter.
- Write commit messages that say what changed and why.
- Describe user-visible behaviour changes in the PR body, and say which platforms you actually ran on. Pupil ships on macOS, Windows, and Linux, and plenty of this code is platform-conditional.

## Reporting bugs

Open an issue using the bug template. The desktop app writes a rotating log to `logs/pupil.log` inside its app data directory:

| Platform | Path |
|---|---|
| macOS | `~/Library/Application Support/com.pupil.desktop/logs/` |
| Windows | `%APPDATA%\com.pupil.desktop\logs\` |
| Linux | `~/.local/share/com.pupil.desktop/logs/` |

Attaching the relevant portion makes a report far easier to act on.

For security issues, please do **not** open a public issue. See [`SECURITY.md`](./SECURITY.md).
